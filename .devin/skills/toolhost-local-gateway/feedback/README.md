# feedback/

Agents drop observations here — one file per finding,
`YYYY-MM-DD-<slug>.md`. The maintainer reads and harvests them
manually; nothing here is automated.

Write one when you hit:

- a bug or surprising behavior in the gateway
- a workaround you had to invent that the skill should just document
- a missing capability (something you wanted `toolhost__*` or the CLI to do)
- a gap or error in SKILL.md itself

Keep it three lines, not an essay:

```markdown
# short title

what I tried / what happened / what I expected
suggestion (optional)
```
